## 🌍 Overview

*GeoQuery AI* is a natural-language satellite intelligence system that converts geographical queries into structured investigation, evidence verification, incident generation, and departmental coordination using **multi-temporal Optical and SAR satellite observations**.

The system allows users to describe a geographical requirement in natural language and transforms it into a structured **WHAT – WHERE – WHEN** investigation.

It dynamically coordinates specialist AI and remote-sensing modules, verifies findings using multiple evidence sources, generates structured incidents, and routes them to the relevant operational domain.

---

## 🚀 Project Features

### 🔎 *Query-Driven Intelligence*

- Accepts **natural-language geographical queries** along with an Area of Interest (AoI).
- Identifies:
  - **WHAT** — what needs to be detected or investigated.
  - **WHERE** — the relevant geographical area.
  - **WHEN** — the relevant time period.
- Converts the query into a structured investigation task.

---

### 🧠 *Dynamic Multi-Model Orchestration*

The system dynamically selects and coordinates task-specific modules based on the query.

Supported specialist capabilities include:

- **Visual Question Answering (VQA)**
- **Image Grounding**
- **Change Analysis**
- **Optical-SAR Fusion**
- **Domain-Specific Analysis**
- Remote-sensing VLMs
- Change-detection models
- LLM / Agentic AI workflows

---

### 🛰️ *Multi-Temporal & Multi-Modal Investigation*

- Compares **current and historical satellite imagery**.
- Combines complementary **Optical and SAR observations**.
- Supports analysis of:

  - 🏗️ Construction
  - 🛣️ Roads
  - 🌾 Crops
  - 💧 Water
  - 🌳 Forests
  - 🏙️ Urban areas

- Enables bi-temporal and multi-image change understanding.

---

### 🔍 *Evidence-Based Verification*

Detected changes are not treated as the final answer.

The system:

- Cross-checks detected changes using multiple observations.
- Identifies **agreement or conflict** between evidence sources.
- Performs **cross-source validation**.
- Generates a **confidence score**.
- Provides visual evidence and execution information.
- Supports overlays and heatmaps for verification.

---

### 📋 *Automated Incident Generation*

Verified geographical changes are converted into structured incident reports containing:

- Location
- Coordinates
- Change type
- Dates
- Affected area
- Supporting imagery
- Evidence
- Confidence level

---

### 🧭 *Intelligent Domain Routing*

Generated incidents are categorized and routed to the appropriate domain:

- 💧 **Water Resources**
- 🌾 **Agriculture & Crops**
- 🏗️ **Infrastructure & Urban**
- 🌳 **Forest & Environment**

---

### 🤖 *Agentic Coordination & Automation*

The complete workflow is connected as:

**Query → Orchestrate → Investigate → Verify → Coordinate**

The system maintains:

- Incident tracking
- Execution trace
- Specialist model/tool selection
- Evidence verification
- Domain routing
- Decision-support outputs
